Install once, then open Tarnished Companion. It finds Elden Ring, opens Steam if needed, prepares offline startup, and opens your personal overlay automatically. Load your character as usual. Steam may require its normal sign-in.

The first launch prepares the standard Steam app-ID file automatically. Existing setup files are preserved. No game executable is replaced and your normal Steam launch remains available for protected online play. The companion does not stop anti-cheat services.

Boss health, DPS and fight detection require a supported game build without Easy Anti-Cheat. Live reads are blocked when a protected session is detected. An absent anti-cheat process is not a guarantee about account enforcement.

If you have problems contact Koné Labie.

Choose a category

Choose a category before creating a new character while this app and the game are running. Existing saves, prepared DLC saves and NG+ do not unlock time recording. Use the same category in LiveSplit.

In LiveSplit, select Elden Ring and your category, activate SoulSplitter, select Game Time, then choose Control → Start TCP Server. Timing starts and stops automatically. Escape does not trigger a pause here.

SoulSplitter setup guide · Current run rules

Keep LiveSplit visible in your recording. Local observations can flag missing evidence or inconsistent progress; they cannot certify a run or prove cheating. Boss results can arrive after the game saves. A process ending cannot distinguish a crash from a normal exit.

Stored timing records and exports are signed. Editing or deleting protected records locks recording and export. A signature proves possession of this local key, not honest gameplay. Share this fingerprint separately with a reviewer before the run:

Export preserves the signed record in a .tlrun package. When a server recipient is configured, the report is encrypted for that recipient. A local signature does not establish leaderboard eligibility; review still requires trusted evidence and the original recording.
