Code and data
- Boss event-flag catalog and boss names: Ghostbroker / Elden Ring Progression Tracker, GPL-3.0; adapted from the public repository https://github.com/Ghostbroker/elden-ring-progression-tracker .
- Save parsing layout: zebbedaja / er-save-parser, MIT; see source/data/save-parser-MIT.txt.
- Boss event flag block mapping references SoulSplitter. The bundled table is data; project: https://github.com/FrankvdStam/SoulSplitter .
- Read-only game memory layout reference: fromsoftware-rs CSFeManImp / TagHudData / WorldChrMan / ChrIns / CSChrDataModule, dual MIT OR Apache-2.0. Project: https://github.com/vswarte/fromsoftware-rs .
- Hostile-team numeric IDs reference the SoulsMods Elden Ring EMEDF TeamType enum: https://soulsmods.github.io/emedf/er-emedf.html#TeamType .
- Combat reference: factual damage-negation values from the community ER PvE spreadsheet, App Ver. 1.17.1, https://docs.google.com/spreadsheets/d/1BVwmKqB8pvuyJkSTGYOM2kAJxFMQ0jVsc6aKYz_Upes/edit ; outgoing damage/status facts from Tarnished.app and linked community references. Credit belongs to their maintainers and contributors. Full per-encounter links, retrieval hash, interpretation, and limitations are in source/data/boss-combat-sources.md. Source prose and artwork are not bundled as part of this reference.
- Combat icons are original project SVG artwork under the project GPL-3.0-or-later license.
- Saved equipment-name catalog: source/data/equipment-catalog.json is a reduced, modified reference from oisis and contributors / EldenRing-SaveForge, GNU GPL version 3, commit ee1042d7a5bd933f91e6f8a0162e0e0237a1c4c5. Upstream: https://github.com/oisis/EldenRing-SaveForge/tree/ee1042d7a5bd933f91e6f8a0162e0e0237a1c4c5 . Modifications made 2026-10-22 reduce tables to names, equipment groups, upgrade bounds and confirmed weapon-family anchors. Pinned input URLs and SHA-256 values are retained in the generated JSON; source/data/build-equipment-catalog.py regenerates it. No artwork is copied from this source. The GPL-3.0 license is included in LICENSE.txt. Full attribution, field references and interpretation are in source/data/equipment-catalog-sources.md.
- Saved build layout references include ER-Save-Lib UserDataX (https://github.com/ClayAmore/ER-Save-Lib/blob/master/src/save/user_data_x.rs) and SaveForge's equipment reader / weapon identity rules at the pinned commit above. Item names remain the property of their respective owners. Last-saved snapshots do not represent every live equipment change or temporary buff.

Boss portraits
- Portraits are bundled as local thumbnails for this personal overlay. Sources include the Elden Ring Boss API (https://eldenring.fanapis.com/) and image pages from the community-maintained Elden Ring Wiki (https://eldenring.fandom.com/). Contributors and file details are available on those source pages. Some duplicate or paired encounters reuse a related boss image where a dedicated portrait was unavailable.
- Elden Ring game imagery and character art are owned by FromSoftware / Bandai Namco. This project is an unofficial fan-made companion and is not affiliated with them.
